## Из-за чего тесты падают

- **Повторный `Order`.** Каждому заказу нужен новый номер. Портал генерирует его сам (текущее время в миллисекундах).
- **`ExpiryDate` в прошлом.** Указывайте будущую дату. Портал ставит конец завтрашнего дня.
- **Суммы в MDL вместо минимальных единиц.** `100` — это 1,00 MDL.
- **Истёкший токен.** Токен живёт около 4 часов; после `401` снова вызовите `/auth`.
- **Товары не сходятся.** Если передаёте `Products`, передавайте все поля товара и следите, чтобы `Amount` совпадали с `Amount` услуги.

## Тестовые сценарии

| # | Сценарий | Как | Ожидается |
|---|---|---|---|
| 1 | Аутентификация | `POST /auth` с тестовыми данными | `200`, `access_token` |
| 2 | Неверный пароль | `POST /auth` с неверным паролем | ошибка `AUTHENTICATION_FAILED` |
| 3 | Создание заказа | `POST /api/order` | `200`, `paymentId`, `paymentLink`, `status` `1` |
| 4 | Неверный запрос | `POST /api/order` без `Services` | `400`, `INVALID_PARAMETER` |
| 5 | Без токена | `POST /api/order` без `Authorization` | `401`, `UNAUTHORIZED` |
| 6 | Оплата | открыть `paymentLink`, оплатить тестовой картой | возврат на `LinkUrlSuccess` |
| 7 | Статус | `GET /api/order/merchant/{Order}` | платёж с заполненным `paidDate` |
| 8 | Неизвестный заказ | `GET /api/order/{id}` со случайным ID | `404`, `NOT_FOUND_RECORD` |
| 9 | Уведомление | симулятор **Уведомления** на портале → ваш URL | обработчик проверяет `Hash` и возвращает `200` |
| 10 | Неверный хэш | отправить уведомление с изменённым `Amount` | обработчик его отклоняет |
| 11 | Повторное уведомление | отправить одно уведомление дважды | обработчик обрабатывает его один раз |
| 12 | Hosted checkout | **Order request v0.6** на портале | открывается тестовая страница оплаты Paynet |
| 13 | Возврат | `POST /api/order/refund` по оплаченному платежу | `200` |

## Тестирование с этого портала

Кнопки «Test API Request» вызывают тестовый API прямо из вашего браузера. Это работает на официальном домене портала. Если открыть копию портала с другого адреса, браузер может заблокировать вызовы (CORS) — тогда используйте cURL или Postman. Коллекцию Postman можно скачать в боковом меню.
