# Журнал изменений

## Документация v3.4 — 11.11.2026

- **Спецсимволы в подписи hosted checkout** (проверено реальными отправками формы в тестовую среду): правильные и неправильные функции кодирования для PHP, JavaScript, Python, C#, Java; перенос строки ломает подпись; HTML-теги и HTML-сущности приводят к тому, что Paynet отклоняет форму до проверки подписи. Новый тестовый вектор 3 с `' & ! ( ) *`, кириллицей и румынскими буквами. См. [Подписи](#/guides/signatures).

## Документация v3.3 — 10.11.2026

Уточнения по итогам теста, в котором разработчик, не знакомый с Paynet, сделал интеграцию только по этой документации.

- **Товары:** если передаёте `Products`, обязательны `LineNo`, `Name`, `UnitPrice`, `Quantity`, `Amount`, `TotalAmount`; `Code` и `Description` — необязательны (проверено на тестовой среде). См. [Server-to-server](#/guides/server-to-server).
- **Ссылка на оплату:** сохраняйте `paymentLink` из ответа на создание заказа — в ответах о статусе она сокращена.
- **Возвраты:** полный возврат — `Amount` равен `PaidAmount`; `200` = выполнен; не повторяйте возврат, не проверив статус. Примеры запроса и ответа теперь об одном платеже. См. [Ошибки и статусы](#/guides/errors-and-statuses).
- Даты поиска платежей в таблице форматов: время Кишинёва, без `Z`.
- Уведомления: важен только HTTP-код `200`, тело ответа значения не имеет.
- Getting started: где используется код мерчанта.
- `Customer.PhoneNumber`: необязателен, но без него покупатель вводит телефон на платёжной странице. Примеры теперь его передают.
- **Статусы:** `6` — оплачен, затем частично возвращён; `5` — не оплачен (отказ банка, антифрод) или возвращён полностью.
- **Уведомления:** первое уведомление отправляется после подтверждения оплаты банком-эмитентом (время зависит от банка); интервалы повторов не изменились.
- **Пример уведомлений в SDK:** уведомление сохраняется до ответа `200`, заказ выполняется по сохранённой записи.
- `linkUrlSuccess` / `linkUrlCancel` в ответах о платеже могут быть `null` (справочник API, типы Node.js SDK).
- `Lang`: регистр не важен; при неизвестном значении страница открывается на английском (проверено на тестовой среде).
- Пример магазина теперь скачивается архивом с этого портала.

## Документация v3.2 — 10.11.2026

- **Официальные SDK для PHP и Node.js** (версия 1.0.0, лицензия MIT): авторизация, заказы, статусы, возвраты с проверкой правил, сохранённые карты, выписки, уведомления, форма hosted checkout, ошибки. Проверены на тестовой среде. См. [SDK](#/guides/sdk).
- **Мобильные приложения**: как принимать оплату в приложении через ваш сервер и страницу Paynet. См. [Мобильные приложения](#/guides/mobile-apps).
- **Поиск платежей:** `from`/`to` — время Кишинёва; пустой период — `404 NOT_FOUND_RECORD`. Исправлена коллекция Postman.
- `Quantity` товара — в сотых долях (`100` = 1 шт.).

## Документация v3.1 — 10.11.2026

- **Новая коллекция Postman** с окружениями TEST и PRODUCTION: токен получается сам, каждый заказ уникальный, данные передаются между запросами. Проверяется прогоном на тестовой среде. См. [Тестирование → Postman](#/guides/testing).
- **Шпаргалка по ошибкам** с колонкой «повторять запрос?»; добавлены `405`, `415` и `404` с пустым телом (проверено на тестовой среде). См. [Ошибки и статусы](#/guides/errors-and-statuses).
- **Расписание повторов уведомлений:** 9 попыток примерно за 25 минут. **IP-адреса** Paynet для файрвола. См. [Уведомления](#/guides/notifications).
- 3-D Secure и причина отказа в разделе статусов; раздел «Обращение в поддержку».
- Боковое меню с иконками; таблицы параметров читаются на телефоне.

## Документация v3 — 09.11.2026

- **Пример магазина на Node.js** — полная интеграция без внешних библиотек. Проверяется сквозным тестом на тестовой среде: покупка, оплата, уведомление, возврат. См. [Пример магазина](#/guides/example-shop).
- **Имитированные ответы для тестов отказов**: статусы `3`, `5`, `6`, ошибки возврата, `401`, `errorInfo`, подписанные уведомления. См. [Тестирование](#/guides/testing).
- **Спецификация API сверена с реальными ответами** тестовой среды: `/auth` с неверным паролем возвращает `401` (а не `500`); описаны формат `401` по токену и формат `errorInfo`; добавлено поле `amount.paidAmount`; добавлены схемы ответов возврата, поиска и выписки.
- **Сохранение карт проверено на тестовой среде:** тому же покупателю карта показывается, чужому — нет. См. [Сохранение карт](#/guides/saved-cards).
- **Полные обработчики уведомлений** на Node.js и PHP; логика Node.js-версии проверяется при каждой сборке.
