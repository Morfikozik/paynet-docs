# Чек-лист запуска

## Перед переходом в продакшн

**Доступы и настройки**

- [ ] Вы получили от Paynet: боевого пользователя API, код мерчанта, код торговой зоны и **два** секретных ключа (для подписи hosted checkout и для уведомлений).
- [ ] Код использует боевые адреса: API `https://ecom-api.paynet.md`, форма hosted checkout `https://paynet.md/ecom/checkout`.
- [ ] Секреты хранятся в настройках сервера (переменные окружения, vault), а не в коде или фронтенде.
- [ ] Ваш callback URL (HTTPS) зарегистрирован в Paynet.
- [ ] `LinkUrlSuccess` и `LinkUrlCancel` указывают на боевые страницы.

**Платежи**

- [ ] Каждый заказ магазина получает свой уникальный номер `Order`, в том числе после перезапусков и при параллельных запросах.
- [ ] `ExpiryDate` вычисляется по местному времени Кишинёва (`Europe/Chisinau`), например «сейчас + 1 день», а не задана жёстко.
- [ ] Суммы передаются в минимальных единицах и совпадают с итогом корзины.
- [ ] Hosted checkout: подпись считается на сервере и проходит [тестовые векторы](#/guides/signatures).

**Уведомления**

- [ ] Обработчик проверяет заголовок `Hash` ключом уведомлений.
- [ ] Обработчик читает `Payment.Id` и `Payment.ExternalId` (именно в таком написании).
- [ ] Обработчик идемпотентен (один `Payment.Id` = одно выполнение заказа).
- [ ] Обработчик проверяет, что `PaidAmount` равен `Amount` (если нет согласованной с Paynet акции).
- [ ] Обработчик отвечает `200` только после сохранения заказа.
- [ ] Резервная задача проверяет неоплаченные заказы через `GET /api/order/{paymentId}`, если уведомление не пришло. О неуспешных платежах уведомлений нет.

**Эксплуатация**

- [ ] Токен кэшируется и обновляется при `401`.
- [ ] Ошибки логируются вместе с `traceId`.
- [ ] Заказ не помечается оплаченным только потому, что покупатель вернулся на `LinkUrlSuccess`.
- [ ] Возвраты и выписки протестированы, если вы их используете.

## После запуска

- Проведите один реальный платёж на небольшую сумму и верните его.
- Сверьте платежи первого дня с выпиской (`GET /api/statement`): вы получаете `PaidAmount` за вычетом комиссии Paynet.
