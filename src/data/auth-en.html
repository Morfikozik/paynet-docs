All API requests require authentication using the following headers:

Authorization

Value: Bearer {{token}}. The token must be obtained via the /auth endpoint.

Example Headers:

Headers:
Authorization: Bearer MFL3Az5eYT9JFAxT....L2iG20KPnDQw6Zhw5uW7QftBpATXdP_......
Accept-Language: en-US
Content-Type: application/json

Note: You can obtain your API credentials from the PayNet Developer Portal after creating an account. You will need:

  • username — your user identifier
  • password — your account password
