Toate cererile către API necesită autentificare dublă utilizând următoarele antete (headers):

Authorization

Valoarea Bearer {{token}} , tokenul trebuie obținut prin metoda de autentificare /auth

Exemplu de Headere:

Headere:
                 Authorization:   Bearer MFL3Az5eYT9JFAxT .... L2iG20KPnDQw6Zhw5uW7QftBpATXdP_ ......
                 Accept-Language:   ro-RO
                 Content-Type:   application/json

Notă: Puteți obține credențialele API în portalul pentru dezvoltatori PayNet după crearea unui cont. Este necesar să obțineți username (numele utilizatorului) și password (parola).
