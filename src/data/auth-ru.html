Все запросы к API требуют двойной аутентификации с использованием следующих заголовков в header:

Authorization

Значение Bearer {{token}} , значение токена необходимо получить на методе Авторизации /auth

Пример Заголовков:

Заголовки:
                 Authorization:   Bearer MFL3Az5eYT9JFAxT .... L2iG20KPnDQw6Zhw5uW7QftBpATXdP_ ......
                 Accept-Language:   ru-RU
                 Content-Type:   application/json

Примечание: Вы можете получить свои API-учетные данные на портале разработчиков PayNet после создания учетной записи. Вам необходимо получить username - название пользователя, password - это будет пароль
